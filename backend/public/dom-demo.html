JavaScript DOM Manipulation Demo

Academic demonstration of imperative DOM access and event listeners (Assignment 11).

Concepts Demonstrated:
  • document.getElementById() for selecting DOM elements
  • addEventListener("click", handler) for event binding
  • element.value for reading input data
  • Client-side validation checking for empty/whitespace input
  • element.innerHTML for dynamic DOM modification

Academic Note: This standalone page demonstrates traditional imperative DOM manipulation. In the main EcoCycle application, React handles DOM updates declaratively via the Virtual DOM and useState.
